# 전략 — 흔한 트렌드 블로그보다 한발 앞서는 4가지 구조

"실검 보고 → 글 쓰고 → 애드센스" 구조는 누구나 하기 때문에 경쟁이 극심하고, 실검 글의 수명은 몇 시간에 불과합니다. 이 사이트는 그 구조 위에 **4가지 구조적 우위**를 얹어 설계되었습니다.

## ① 사전 포지셔닝 (Pre-positioning) — 검색량이 오기 전에 도착해 있기

실검 대응은 이미 늦은 싸움입니다. 대형 언론사와 수천 개 블로그가 같은 키워드로 몇 분 만에 쏟아지니까요. 반면 **예정된 이벤트**(연휴, 스포츠 대회, 신제품 발표, 수능, 세일, 제도 시행)는 검색량이 언제 폭증할지 미리 알 수 있습니다.

- `data/events.json`이 이벤트 캘린더 역할 → `npm run plan`이 D-30/14/7/3/1 시점마다 "지금 쓰면 선점" 알림
- 검색량이 적을 때(경쟁 약할 때) 발행 → 구글·네이버가 색인하고 초기 순위 확보 → **검색 폭증 시점에 이미 상위**
- 이벤트 종료 직후 "결과·결산" 글 타이밍도 자동 알림 (결과 검색은 이벤트 당일보다 큰 경우가 많음)

> 실행 규칙: 기획 리포트의 ①번(이벤트 알림)을 ②번(실시간 트렌드)보다 항상 우선하세요. 실검 글은 "한글 관련성 + 뉴스 맥락"이 있는 것만 선별해 하루 1개 이하로.

## ② 콘텐츠 회전 (Content Rotation) — 같은 URL을 계속 키우기

새 글만 쏟아내는 사이트는 글 하나하나가 약합니다. 이 사이트는 **하나의 URL에 신호를 누적**시킵니다.

- 이벤트 확정 정보가 나오면 새 글이 아니라 **기존 글을 업데이트**하고 `updated:` 날짜 변경
- 빌드가 `<lastmod>`(사이트맵), `dateModified`(구조화 데이터), "업데이트" 배지를 자동 반영 → 검색엔진에 신선도 신호
- 예: "추석 총정리" 글 하나가 [예매 일정 발표 → 통행료 확정 → 연휴 직전 교통 정보]로 3번 회전하며 매번 재색인
- 매일 자동 빌드 덕에 홈·캘린더의 D-Day가 항상 최신 → 사이트 전체가 "살아있는 사이트"로 평가

## ③ 허브-스포크 구조 + 빠른 색인 — 작은 사이트의 권위 만들기

- **필러 페이지**(예: "하반기 빅 이벤트 캘린더")가 허브가 되고 개별 글이 스포크로 내부 링크 → 주제 권위(topical authority) 형성
- `/calendar/` 페이지는 매일 갱신되는 상시 유입 페이지 (즐겨찾기·재방문 유도)
- FAQ 블록 → FAQPage 구조화 데이터 → 검색결과에서 차지 면적·클릭률 상승
- **IndexNow 핑**으로 발행 즉시 네이버·빙 계열에 색인 요청 (트렌드 콘텐츠는 색인 속도가 곧 순위)
- 구글은 Search Console 사이트맵 + 내부링크로 크롤링 우선순위 확보

## ④ 원소스 멀티유즈 — 유입 채널 다각화

같은 리서치(수집 데이터 + 초안)를 여러 채널로 재활용해 검색 의존도를 낮춥니다.

- **네이버 블로그/티스토리 요약본**: 본문 요약 + "전체 내용은 사이트에서" 링크 (네이버 검색은 네이버 블로그를 우대)
- **커뮤니티 정보성 공유**: 이벤트 정리 표는 커뮤니티에서 자연 확산되기 좋은 포맷
- **뉴스레터(후순위)**: 트래픽이 쌓이면 "이번 주 이벤트 캘린더" 뉴스레터로 재방문 확보

## 하지 말아야 할 것 (수명 단축 요인)

| 유혹 | 결과 |
|---|---|
| 하루 10개+ 무검수 대량 발행 | 구글 "확장 콘텐츠 남용" 스팸 강등 → 도메인 전체 타격 |
| 실검 전부 따라가기 | 수명 몇 시간짜리 글 양산, 사이트 정체성 상실 |
| 뉴스 본문 복붙·짜깁기 | 저작권 + 중복 콘텐츠 페널티 |
| 낚시성 제목 | 체류시간 하락 → 순위 하락 (CTR만 높은 글은 오히려 독) |
| 종목 추천·의료 조언 | YMYL 최고 검열 영역 + 법적 리스크 |

## 성장 단계별 목표 (현실적 기준)

| 단계 | 기간 | 목표 | 핵심 활동 |
|---|---|---|---|
| 씨앗 | 0~1개월 | 글 20~30개, 서치콘솔·서치어드바이저 등록 | 반자동 운영, 이벤트 선점 글 위주 |
| 발아 | 1~3개월 | 일 100~500뷰, 애드핏 게재 + 애드센스 신청 | 회전 업데이트 루틴 정착 |
| 성장 | 3~6개월 | 일 1,000뷰+, 애드센스 승인, 쿠팡 연계 | 잘 되는 주제 클러스터 확장 |
| 수확 | 6개월+ | 월 수십만 뷰 시즌 스파이크 | 완전 자동화 + 시즌 이벤트 총력 |

트래픽과 수익은 보장되지 않으며, 특히 첫 3개월은 색인·신뢰 축적 기간이라 수익이 거의 없는 것이 정상입니다. 이 구조의 가치는 "매일 반복 가능하고, 자산(글·도메인 신뢰)이 누적된다"는 데 있습니다.
