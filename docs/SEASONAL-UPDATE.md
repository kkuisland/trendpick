# 시즌 페이지 갱신 절차

클라우드 루틴 「케이트렌드 시즌 페이지 관리」가 매일 이 문서대로 움직인다. 사람이 손으로 갱신할 때도 같은 절차를 따른다.

작업 목록은 `data/seasonal-updates.json`, 페이지 목록과 장기 갱신 계획은 `content_calendar.md`, 콘텐츠 원칙은 `CLAUDE.md` 에 있다. **CLAUDE.md 3절(콘텐츠 원칙)을 먼저 읽는다.**

## 1. 오늘 할 작업 고르기

`data/seasonal-updates.json` 의 `tasks` 중 아래를 모두 만족하는 것만 처리한다.

- `status` 가 `"open"`
- `from` ≤ 오늘(KST) ≤ `until`
- `every_days` 가 있으면 `last_checked` 로부터 그 일수 이상 지났거나 `last_checked` 가 null

해당 작업이 없으면 **아무것도 바꾸지 않고 끝낸다.** 이것이 정상 동작이다.

`until` 이 지났는데 아직 `open` 인 작업은 `status` 를 `"expired"` 로 바꾸고 보고에 남긴다 (사람이 확인해야 함).

## 2. 작업 처리

각 작업의 `what` 을 그대로 수행한다. 원칙:

1. **공식 출처로만 고친다.** `sources` 에 적힌 곳(정부·기관·대학 공식 사이트, 주최 측 공지)을 웹 검색·페이지 열람으로 확인한다. 언론 기사는 공식 발표를 옮긴 것일 때만 쓴다. 블로그·카페·나무위키는 근거로 쓰지 않는다.
2. **찾지 못하면 고치지 않는다.** 추측하거나 작년 값을 올해 값처럼 쓰지 않는다. 이 경우 페이지는 그대로 두고 `log` 에 "미발표 — 확인한 곳" 을 남긴다.
3. **고친 페이지에는**
   - 프런트매터에 `updated: 오늘 날짜` 를 넣거나 바꾼다.
   - 본문 맨 아래 **최종 확인일**을 오늘로 바꾸고, 출처 목록에 새로 쓴 공식 출처를 추가한다.
   - 요일이 붙은 날짜는 요일을 검산한다.
4. 작업 범위 밖의 글·코드는 건드리지 않는다. 계산기 스크립트는 `tool` 에 적힌 파일만, `what` 이 시킨 값만 바꾼다.
5. 작업을 끝냈으면 `status` 를 `"done"` 으로 바꾼다. 일부만 했으면 `open` 으로 두고 남은 것을 `log` 에 적는다.

모든 작업에서 `last_checked` 를 오늘로 바꾸고, `log` 에 `"YYYY-MM-DD: 한 일 또는 미발표 사유"` 한 줄을 추가한다.

## 3. 검증과 배포

```bash
npm ci
node scripts/build.mjs --strict
```

- 빌드가 실패하거나 새 죽은 링크 경고가 생기면 **커밋하지 말고** 원인을 보고하고 끝낸다.
- 페이지를 고쳤으면 페이지·도구·`data/seasonal-updates.json` 을 함께 커밋한다.
  - 메시지: `content: 시즌 갱신 — <작업 id> (<무엇을 바꿨는지>)`
- 페이지는 그대로이고 `every_days` 작업의 `last_checked`/`log` 만 바뀌었으면 `chore: 시즌 점검 로그 — <작업 id>` 로 커밋한다. 매일 도는 작업(`every_days` 없음)의 점검 기록만 바뀐 경우에는 커밋하지 않는다.
- `git push origin main`. 거절되면 `git pull --rebase origin main` 후 한 번만 재시도한다. force push 금지.
- 샌드박스에서 ktrend.kr 접속이 막혀 라이브 확인이 안 될 수 있다. 막히면 "라이브 확인 불가" 로 보고한다.

## 4. 보고

한 줄씩:
- 처리한 작업: id / 결과 (갱신함 · 미발표 · 만료)
- 바꾼 파일
- 빌드 결과, 커밋 해시
- 사람이 봐야 할 것 (만료된 작업, 출처끼리 다른 값 등)

## 새 작업 추가하기

새 시즌 페이지를 만들면 `content_calendar.md` 에 한 줄, `data/seasonal-updates.json` 에 갱신 작업을 추가한다. `what` 은 루틴이 이 글만 보고 실행할 수 있을 만큼 구체적으로 쓴다 (무엇을 확인하고, 어느 부분을 어떻게 바꾸고, 못 찾으면 어떻게 두는지).
