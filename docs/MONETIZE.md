# 수익화 로드맵 — 단계별 체크리스트

수익원은 "쉽게 열리는 것부터" 순서대로 쌓습니다. 각 단계는 이전 단계와 병행 유지합니다.

## 0단계 — 기반 (첫 주에 완료)

- [ ] **도메인 구입** (연 1~2만 원, 가비아/클라우드플레어 등). `github.io` 서브도메인은 애드센스 승인이 사실상 불가능하므로 필수 투자입니다.
- [ ] GitHub Pages 배포 + 커스텀 도메인 연결 (README 배포 절차)
- [ ] `config/site.config.json` → `site.url` 실제 도메인으로 변경
- [ ] **구글 서치콘솔** 등록: 소유 확인 메타태그 값을 `verification.google`에 입력 → 재배포 → 확인 → `sitemap.xml` 제출
- [ ] **네이버 서치어드바이저** 등록: 동일하게 `verification.naver` 입력 → 사이트맵·RSS 제출 (네이버 유입의 시작점)
- [ ] `apis.indexnow.key`에 임의 32자 키 설정 (즉시 색인)
- [ ] GA4 생성 → `analytics.ga4`에 측정 ID 입력 (수익 분석의 기초 데이터)

## 1단계 — 카카오 애드핏 (글 10~15개 시점)

애드센스보다 승인 문턱이 낮아 첫 수익원으로 적합합니다. 단가는 낮지만 "수익 파이프 개통"이 목적입니다.

- [ ] [adfit.kakao.com](https://adfit.kakao.com) 가입 → 사이트 등록 → 광고 유닛 생성 (PC 728×90, 모바일 320×100)
- [ ] `monetization.adfit`에 유닛 ID 입력 + `enabled: true` → 재배포하면 모든 `{{ad}}` 슬롯에 자동 게재

## 2단계 — 쿠팡 파트너스 (병행 시작 가능)

트렌드·이벤트 콘텐츠와 가장 궁합이 좋은 수익원입니다 (추석 선물, 블프 딜, 응원용품…). 광고보다 단가가 높고 시즌 스파이크 때 폭발력이 있습니다.

- [ ] [partners.coupang.com](https://partners.coupang.com) 가입 (실적 요건 확인)
- [ ] `monetization.coupang.enabled: true` + 대시보드에서 만든 다이내믹 배너 ID 입력
- [ ] 개별 상품은 파트너스 대시보드에서 링크 생성 → 글에 `{{coupang url="링크" title="상품명"}}`
- [ ] 수수료 고지 문구는 자동 삽입됨 (제거 금지 — 법적 의무)
- 팁: `data/events.json`의 각 이벤트에 적어둔 `monetize` 필드가 연계 아이디어입니다. 쇼핑 시즌 이벤트(추석·블프·크리스마스·설) 글에 집중 배치하세요.

## 3단계 — 구글 애드센스 (글 25~30개 + 운영 1~2개월 시점)

메인 수익원. 승인 심사가 까다로우니 아래를 갖춘 뒤 신청하세요.

승인 준비물 (이 사이트에 이미 내장된 것):
- ✅ 개인정보처리방침 페이지 (`/privacy/` — 광고 쿠키 고지 포함)
- ✅ 소개·문의 페이지
- ✅ 반응형·빠른 로딩·명확한 내비게이션
- ✅ sitemap, robots.txt

신청 전 갖출 것:
- [ ] 검수된 정보성 글 25개 이상 (독창적 정리 + 표·FAQ 포함 — 이 사이트의 기본 포맷)
- [ ] 커스텀 도메인 + 몇 주간의 꾸준한 발행 이력
- [ ] `contact.md`에 실제 연락 가능한 이메일 기재

승인 후:
- [ ] `monetization.adsense.enabled: true` + `client`(ca-pub-…) 입력 → `{{ad}}` 슬롯·ads.txt·로더 스크립트 자동 반영 (애드핏은 백업으로 꺼도 되고 병행 정책 확인 후 유지해도 됩니다)
- [ ] 애드센스 대시보드에서 자동 광고는 끄고 슬롯 위주로 시작 (체류시간 보호)

## 4단계 — 확장 수익원 (트래픽 안착 후)

| 수익원 | 적합 콘텐츠 | 비고 |
|---|---|---|
| 여행 제휴 (아고다·클룩·트립닷컴 등 제휴 플랫폼) | 연휴·직관 여행 글 | 링크프라이스/쿠팡트래블 등 경유 |
| 통신사·금융 제휴 (제휴 네트워크 경유) | 신제품 사전예약, 연말정산 | 고단가, 규정 준수 필수 |
| 뉴스레터 스폰서 | 주간 이벤트 캘린더 | 구독자 1천+ 시점 |
| 콘텐츠 제휴·외고 | 정리 포맷 자체가 포트폴리오 | 문의 페이지로 인입 |

## 수익 기대치 (현실적인 숫자)

한국 정보성 블로그 기준 대략적인 감각치입니다 (주제·시즌에 따라 편차 큼):

| 일 방문자 | 애드센스 월 수익 감각치 | 비고 |
|---|---|---|
| ~100 | 몇천 원 | 색인 축적기 (0~2개월) |
| 500 | 3~10만 원 | 애드핏+쿠팡 합산 시 상향 |
| 2,000 | 20~60만 원 | 시즌 스파이크 월은 2~3배 |
| 10,000 | 100만 원+ | 쿠팡 시즌 수익이 광고 추월 가능 |

**정직한 전제**: "고정 수익"은 어떤 사이트도 보장하지 못합니다. 이 시스템이 보장하는 것은 ① 매일 돌아가는 반복 구조 ② 글·도메인 신뢰의 누적 ③ 시즌마다 재사용되는 이벤트 자산입니다. 수익의 변동성은 시즌 이벤트(추석→블프→설)로 평탄화하는 것이 이 사이트의 설계 의도입니다.
