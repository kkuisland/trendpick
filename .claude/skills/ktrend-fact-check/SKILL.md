# 사실 확인 기준

케이트렌드 독자는 글을 보고 그대로 신청·납부·예매한다. 날짜·금액·자격 요건이 틀리면 돈과 기회를 잃는다.
자동 생성 글은 사실 오류가 잦다(노동절 글은 휴일대체 가능/불가가 정반대로 나온 적이 있다).

## 근거로 쓰는 것 (위가 우선)

1. 법령·고시 — 국가법령정보센터(law.go.kr), 부처 고시·공고
2. 정부·공공기관 공식 페이지 — 국세청·홈택스, 복지로, 정부24, 고용노동부, 한국교육과정평가원, 코레일 등
3. 주최 측 공식 공지 — 행사·기업 공식 사이트, 공식 보도자료
4. 언론 기사 — **공식 발표를 옮긴 경우에만**, 그리고 원 발표를 찾을 수 있으면 원 발표를 링크

블로그·카페·나무위키·AI 요약은 근거로 쓰지 않는다.

## 확인하지 못했을 때 — 흐리게 쓰지 않는다

이 사이트는 **「문제가 될 글은 책임을 피하게 돌려서 쓰라」는 방식을 쓰지 않기로 정했다.** 틀린 사실은 표현을 흐려도 독자에게 그대로 해를 끼치고, 구글도 알맹이 없는 글을 내린다. 이 방향을 되돌리지 않는다.

- 확인 안 되는 문장 → **지운다.** 「~라고 알려져 있다」, 「~일 수 있다」로 덮지 않는다.
- 핵심 정보(도구 계산 기준, 날짜, 금액)를 확인 못 함 → 그 글·후보를 **만들지 않는다**(`page-queue.json` 은 `blocked` + 사유).
- 올해 값이 아직 발표 전 → 작년 값을 쓰되 본문·표·도구에 **「작년 기준」** 을 분명히 쓰고, `data/seasonal-updates.json` 에 반영 작업을 추가.
- 출처끼리 다르면 공신력 높은 쪽을 따르고 차이를 본문에 밝힌다.
- 「[확인 필요]」·「[confirm …]」 같은 검수 메모는 **공개 글에 남기지 않는다.** 빌드가 잡는다(`node scripts/build.mjs --strict` 는 남아 있으면 실패).

## 글에 남기는 것

- 수치에는 출처 기관 이름을 문장 안에, 링크는 「출처와 업데이트 이력」에 모은다.
- **최종 확인일** (오늘, KST) — 갱신할 때마다 바꾼다.
- 도구 파일의 기준 상수 옆에 출처 주석.

## 검수 대기 글을 볼 때

어드민(`/admin/`) 「검수 대기 글」은 틀리면 독자가 돈·건강·권리를 되돌릴 수 없게 잃는 주제라 자동 발행하지 않은 글이다(`scripts/plan.mjs` 의 `REVIEW_PATTERNS`, `docs/WRITING.md` 5장).
발행을 권하기 전에 위 기준으로 핵심 주장마다 「주장 | 맞음/틀림/확인 불가 | 근거 URL」 표를 만들어 사장님께 보여 준다.

## 하지 않는 것

- 제휴 링크(쿠팡·트립닷컴 추적 링크)를 열어 보기 — 자기 클릭은 파트너스 정책 위반 소지
- 뉴스 본문·이미지 복사
