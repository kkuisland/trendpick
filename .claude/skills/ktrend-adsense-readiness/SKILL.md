# 애드센스 재신청 점검

CLAUDE.md 2절 1단계(애드센스 승인)의 완료 조건을 확인한다. 하나씩 실제로 확인하고, 통과/미통과와 근거를 표로 보고한다.

## 점검표

| # | 항목 | 확인 방법 |
|---|---|---|
| 1 | 미완성 표시 0 | `node scripts/build.mjs --strict` 통과 (「[확인 필요]」·빈칸 문구가 남으면 실패) |
| 2 | 깨진 내부 링크 0 | 같은 빌드의 「죽은 내부 링크」 0건 |
| 3 | 필수 페이지 4종이 완성 | 소개·연락처·개인정보처리방침·**이용약관**. 연락처에 실제 이메일, 「여기에 기재하세요」 같은 자리표시 없음, 이름은 모두 「케이트렌드」 |
| 4 | 공개 글마다 출처·확인일 | 발행 글(`draft: false`, `noindex` 아님) 본문에 공식 출처 링크와 「최종 확인일」 |
| 5 | 얇은·지난·방향 밖 글이 노출되지 않음 | 끝난 일회성 행사, 연예인 신상, 뉴스 재가공 글은 `noindex`·목록 제외 또는 사장님 승인 후 삭제 |
| 6 | 핵심 글에 도구 | 시즌 페이지 3편 이상에 계산기·판별기·D-day (`public/assets/tools/`) |
| 7 | 기술 | 사이트맵·robots 정상, ads.txt 한 줄, 첫 화면에 애드센스 로더, `node scripts/health-check.mjs` 0 또는 주의만 |
| 8 | 서치콘솔 | 사이트맵 제출, 주요 글 색인됨 (사장님 화면에서 확인 — 결과를 받아 적는다) |

빈 글 수(공개 글이 1~2편뿐인 카테고리)도 함께 본다 — 빈 카테고리는 noindex·사이트맵 제외(빌드가 처리).

## 판정

- 모두 통과 → 사장님께 「애드센스 → 사이트 → ktrend.kr → 검토 요청」 안내. 거절 사유 화면을 받으면 그 사유부터 다시 맞춘다.
- 하나라도 미통과 → 고칠 목록을 우선순위로. **글 삭제·URL 변경은 항목마다 사장님께 묻는다.**

## 승인 후 — 광고 켜기와 배치 (CLAUDE.md 6절)

- 켜기: 어드민 「애드센스」 → 「광고 켜기」(또는 `config/site.config.json` 의 `monetization.adsense.enabled`). 승인 메일을 받기 전에는 켜지 않는다.
- 계산기 버튼·입력창 바로 옆에 광고를 두지 않는다 — 본문의 `{{ad}}` 가 도구(`<div class="calc"`) 바로 위아래에 있는 글을 찾아 옮긴다.
- 「광고를 눌러 주세요」 같은 문구 금지. 광고가 본문보다 많아 보이지 않게.
