# 케이트렌드 (ktrend.kr) — 마케팅 스킬용 요약

외부 마케팅 스킬(`free-tools`, `programmatic-seo`, `schema`, `site-architecture`)이 처음에 읽는 파일이다.
자세한 기준은 저장소 루트의 `CLAUDE.md` 가 우선한다. 이 파일과 다르면 CLAUDE.md 를 따른다.

- **무엇:** 곧 검색이 몰릴 「날짜가 정해진 반복 이슈」(세금·지원금 신청 기간, 시험·발표일, 시즌 생활, 행사·티켓팅)를 4~8주 먼저 정리하고, 계산기·판별기·D-day 같은 도구를 붙이는 한국어 정보 사이트. 영어판(`/en/`)은 4단계에서 확장.
- **독자:** 한국 일반인. 휴대폰으로 검색해서 들어와 바로 답과 계산 결과를 원한다.
- **수익 모델:** 구글 애드센스 광고(재신청 준비 중) + 일부 제휴 링크. 목표 월 200만 원. **회원가입·이메일 수집·게이팅을 하지 않는다** — `free-tools` 스킬의 리드 수집 부분은 해당 없음.
- **유입:** 네이버·구글 검색. 경쟁자는 블로그·언론·정부 페이지. 이기는 방법은 선점 + 도구 + 공식 출처.
- **기술:** 의존성 없는 자작 정적 사이트 생성기(Node, `scripts/build.mjs`), Railway 배포. 글은 `content/posts/*.md`, 도구는 `public/assets/tools/*.js`(외부 라이브러리 없음). CMS·노코드 도구는 쓰지 않는다.
- **이미 있는 것:** 사이트맵, canonical, Open Graph(PNG), JSON-LD(Article·BreadcrumbList·FAQPage·Organization), 글 단위 `noindex`, 검색 노출 글이 없는 카테고리 자동 noindex.
- **하지 않는 것:** 연예인 사생활·사건사고·루머·정치, 뉴스 재가공, 데이터가 빈 얇은 페이지, 확인 안 된 수치.
