케이트렌드 관리

사장님이 직접 넣고 정할 것을 한곳에 모았습니다. 저장하면 저장소에 커밋되고 1~2분 뒤 사이트에 반영됩니다.

이 브라우저 탭에만 저장되며, 탭을 닫으면 사라집니다.

할 일

색인 요청(검색엔진에 새 글 알리기)은 사장님 PC 의 예약 작업이 매일 오전 9시에 보냅니다. 여기서 할 일은 없습니다.

검수 대기 글

틀리면 독자가 돈·건강·권리를 잃을 수 있어 자동으로 내보내지 않은 글입니다. 읽어 보고 발행하거나, 때가 지났으면 삭제하세요.

구글 서치콘솔 인증

  1. → 「URL 접두어」에 https://ktrend.kr 입력
  2. 인증 방법에서 HTML 태그를 골라 태그를 복사합니다
  3. 아래 칸에 태그를 통째로 붙여 넣고 저장합니다 (값만 넣어도 됩니다)
  4. 1~2분 뒤 서치콘솔로 돌아가 확인을 누릅니다

애드센스

  1. → 사이트에 ktrend.kr 추가 후 검토 요청
  2. 게시자 ID 와 ads.txt 는 이미 사이트에 들어가 있습니다. 따로 붙일 코드는 없습니다
  3. 승인 메일을 받으면 아래 광고 켜기를 체크하고 저장합니다

GitHub 토큰 좁히기

  2. 이름 ktrend-admin, 만료는 원하는 기간, Resource owner 는 kkuisland
  3. Repository access → Only select repositories → kkuisland/trendpick 하나만
  4. Repository permissions → Contents: Read and write 하나만 (Metadata 읽기는 자동으로 붙습니다). 다른 권한은 주지 않습니다
  5. 만든 토큰(github_pat_…)을 Railway → 이 서비스 → Variables 의 GITHUB_TOKEN 에 직접 붙여 넣습니다. 대화창이나 이 화면에는 넣지 않습니다
  6. 재배포가 끝나면 이 화면을 새로고침해 「좁힘 완료」를 확인하고, GitHub 에서 예전 토큰을 삭제합니다
